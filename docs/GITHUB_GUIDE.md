# GitHub Repository Setup (GitHub Desktop)

1. Create/sign in to your GitHub account.
2. Install and open GitHub Desktop.
3. Choose **File → Add Local Repository** if the extracted folder is already a Git repository; otherwise choose **File → New Repository** and select the `CampusFind` folder as the local path.
4. Repository name: `CampusFind`.
5. Ensure `.gitignore` excludes `.venv`, `campusfind.db`, `.env` and uploads.
6. Review the changed files. Commit with summary: `Initial CampusFind MVP`.
7. Click **Publish repository**.
8. For a college project, choose Public only if the team and guide approve. Do not publish private student data, credentials, real claim evidence or personal contact information.
9. Add all team members as collaborators if required.
10. Upload the Review 2 PPT and final report into a `presentations/` or `docs/` folder, then commit and push.

## Suggested repository contents
- Source code and templates
- `README.md` and `requirements.txt`
- `docs/` project report, progress, testing and team contribution records
- `tests/`
- Review presentations and non-sensitive screenshots

Never commit the local database, passwords, `.env`, or real users' private information.
