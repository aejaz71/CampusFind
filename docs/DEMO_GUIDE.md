# CampusFind – Partial Working Model Demonstration

## 1. Project Introduction

CampusFind is an AI-powered smart lost-and-found management system designed for educational institutions.

It provides a centralized platform for students to report lost and found belongings, search for items and identify possible matches.

## 2. Technologies Used

- Frontend: HTML, CSS and Bootstrap
- Backend: Python and Flask
- Database: SQLite
- AI/ML: Scikit-learn
- Matching algorithm: TF-IDF and cosine similarity

## 3. Demonstration of Working Features

### Feature 1: Student Registration and Login
Students can register and log in to access the application.

### Feature 2: Lost Item Reporting
Students can submit reports containing item descriptions, categories, dates and locations.

### Feature 3: Found Item Reporting
Students can report belongings they have found on campus.

### Feature 4: Search Functionality
Users can search for lost and found item reports.

### Feature 5: AI-Based Matching
The system uses TF-IDF and cosine similarity to compare item descriptions and rank possible matches.

### Feature 6: Claim Submission
Students can submit claims for items they believe belong to them.

### Feature 7: Admin Management
Administrators can review claims and manage item statuses.

## 4. Demonstration Procedure

1. Start the Flask application.
2. Open the website in a browser.
3. Register and log in as a student.
4. Submit a lost-item report.
5. Submit a found-item report.
6. Search for relevant items.
7. Demonstrate AI-based matching.
8. Submit a claim.
9. Log in as an administrator.
10. Demonstrate claim review.
